Software Inmobiliaria

Full Stack

Esta es una aplicación web completa para la gestión integral de propiedades inmobiliarias. Desarrollé tanto el frontend como el backend, implementando todas las funcionalidades necesarias para un sistema profesional de real estate.

Características principales:

Autenticación segura

Sistema de login con JWT y encriptación de contraseñas con Bcrypt

CRUD completo

Crear, leer, actualizar y eliminar propiedades con interfaz intuitiva

Base de datos relacional

PostgreSQL para almacenar información estructurada de propiedades

API RESTful

Backend con Express.js siguiendo estándares REST profesionales

Diseño responsive

Funciona perfectamente en desktop, tablet y dispositivos móviles

Validaciones

Validaciones en frontend y backend para garantizar integridad de datos

Stack Tecnológico:

Frontend: React, HTML5, CSS3, JavaScript
Backend: Node.js, Express.js, JWT, Bcrypt
Base de datos: PostgreSQL
Hosting: Netlify (Frontend), Render (Backend)

Sobre mí

Soy un desarrollador web junior Full Stack con muchas ganas de crecer en este mundo del desarrollo. Me formé en un bootcamp intensivo donde adquirí sólidos conocimientos en desarrollo web moderno.

Me encanta crear sitios web que funcionen bien y se vean atractivos. Disfruto mucho tanto del desarrollo frontend como del backend, y me apasiona aprender nuevas tecnologías constantemente.

Fuera del desarrollo, me gusta jugar al fútbol en mi tiempo libre, algo que me ayuda a desconectar y mantener un buen equilibrio entre el trabajo y la vida personal.

Mi filosofía de trabajo

Creo en el código limpio, las buenas prácticas y el trabajo en equipo. Siempre estoy buscando mejorar mis habilidades y enfrentar nuevos desafíos que me ayuden a crecer como profesional.

Además de JavaScript y Node.js, estoy aprendiendo Python y Django para crear aplicaciones web robustas y profesionales. Me interesa mucho trabajar con backend y construir APIs eficientes para proyectos futuros.

También estoy familiarizado con CI/CD usando herramientas como GitHub Actions para automatizar pruebas y despliegues, asegurando que mis proyectos siempre estén actualizados y funcionando correctamente.
